# To-Do List Manager

## 1. Project Description

The To-Do List Manager is a command-line Python application that allows users to manage their daily tasks through a simple and interactive terminal interface.

The application allows users to:

- Add new tasks
- View existing tasks
- Remove tasks
- Mark tasks as completed
- Exit the application

The project was developed as part of the Week 1 Python CLI Application Design and Implementation task.

---

## 2. Objectives

The main objectives of this project are:

- Practice core Python programming concepts.
- Understand object-oriented programming.
- Create a modular application structure.
- Implement user input validation.
- Handle invalid input without crashing.
- Practice writing clean and maintainable code.
- Create basic automated tests.
- Document the project clearly.
